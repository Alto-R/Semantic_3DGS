# Retired DINOv3 3D-first experiments

This directory preserves the DINOv3 3D-first research routes that are no
longer part of the maintained semantic pipeline. The original
repository-relative paths are retained below `source/`.

The archived work includes:

- 3D query-region proposal and association methods;
- anchored, core-first, boundary, plurality, and dense-vote audits;
- SAM and Mask2Former hybrid refinement;
- the schedulers, tests, and method notes for those routes.

Some files existed before these experiments and were modified by them. Their
experimental versions are stored here, while the active paths contain the
earlier maintained versions.

Nothing under this directory is imported or scheduled by the maintained
pipeline. Restore a file to its original path before attempting to run it.
